**Gold Leaf Ghostwriting** is a premium, high-performance web platform built for an elite literary agency. The application serves as a sophisticated digital hub for authors, providing end-to-end services from professional ghostwriting and memoir development to global Amazon KDP distribution and custom author branding.

---

## 🌟 Key Features

* **Premium Luxury Design**: A high-end aesthetic utilizing a "Gold Leaf" palette and sophisticated typography tailored for elite clientele.
* **Dynamic Dark Mode**: Intelligent system-theme detection with a "Luxury Toggle" for seamless transition without flickering.
* **SEO-Optimized Silo Architecture**: Specialized landing pages targeting high-traffic keywords like "Amazon Book Publishing," "Professional Ghostwriting," and "Author Website Design".
* **Lead Generation System**: Secure integration with **Supabase** to capture and manage high-intent project inquiries.
* **Interactive Signature Workflow**: An educational journey page explaining the 5-step lifecycle of professional book publishing.
* **Full-Stack React Architecture**: Built with a modular, scalable structure including dynamic routing and SEO-friendly metadata injection.

---

## 🚀 Tech Stack

* **Frontend**: [React.js](https://reactjs.org/) with [TypeScript](https://www.typescriptlang.org/) for type-safe development.
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) for utility-first UI and advanced Dark Mode logic.
* **Database**: [Supabase](https://supabase.com/) for secure storage of leads and profiles.
* **Routing**: [React Router DOM](https://reactrouter.com/) for fast, SPA-style navigation.
* **Deployment**: [Vercel](https://vercel.com/) for CI/CD and high-availability production hosting.
